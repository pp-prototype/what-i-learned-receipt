# what-i-learned-receipt
학습일지 영수증 웹

## MVP 1.0 - 기록하고, 이미지를 다운로드 받는 정적 웹사이트

### 아이디어
- 내가 매일 기록하는 학습일지를 정형화 하면 어떨까?
- 정형화된 프레임에 맞춰서 간단히 그림일기를 적듯이 사진과 함께 마크다운으로 작성하자
- 타임스탬프를 기록하여 한 장 한 장 학습을 쌓아나가자

### 기획
1. 사용자 관점 경험 스토리라인
    - 웹앱 진입>>(날짜 변경 불가) 오늘 날짜 확인>>사진 업로드하기>>간단히 텍스트로 내용 입력하기>>아래 영수증 발행버튼 클릭, 이미지 다운로드
2. 필요 화면 및 기능 리스팅
    - 화면
        1. 메인화면 : 간단한 엽서와 비슷한 모양의 스타일 카드. 날짜/제목/사진/내용/버튼 항목으로 구분되어 있음. 모바일 화면 대응
    - 기능
        1. 오늘 날짜 확인 기능 : 오늘의 날짜를 YYYY-MM-DD 형식으로 표기. 변경 불가능
        2. 사진 업로드 기능 : 사진 업로드 버튼을 눌러 파일 탐색기를 열 수 있는 기능. 모바일 환경에서 사진 업로드 가능.
        3. 이미지 다운로드 기능 : 작성된 내용을 바탕으로 입력한 데이터 및 사진을 함께 이미지화하여 다운로드 할 수 있는 기능.
3. mvp 개발에 맞춘 일정과 기능 결정
    - 데이터 저장, 로그인, 공유 기능은 제외하고 이미지 다운로드에 집중한다
    - 사진은 1장만 업로드하며, 사진이 없어도 영수증을 발행할 수 있다
    - 입력 항목은 제목, 오늘 배운 것, 짧은 메모 정도로 간결하게 둔다
    - 결과물은 모바일에서 보기 좋은 세로형 PNG 이미지로 다운로드한다
    - 마크다운은 MVP 이후 확장 기능으로 고려한다

### 빌드 검증

```bash
npm install
npm run check
```

### 로컬 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:8000/`을 연다. 이 명령은 Tailwind와 JavaScript를 `dist`에 빌드한 뒤 올바른 디렉터리를 로컬로 제공한다.

운영 배포는 GitHub Actions의 `Deploy GitHub Pages` 워크플로를 수동 실행한다. 배포 전 Google OAuth Client와 Supabase Google Provider 설정, 조직의 비용 상한을 확인한다.
